Preinstalled System Font List of Xiaomi Android MIUI

Preinstalled system font lists are very necessary and useful for frontend designers. Designers can claim the font family names at CSS more accurately if they got the font list. Maybe more designers prefer using web fonts which will make sure that every user from every different device will see the same font. However, I will consider using local fonts first because the web fonts will cost more data usage.

Microsoft Windows and Apple macOS do provide the system font list, this is praiseworthy. There is also a GitHub repository called adrg/os-font-list that collects system font lists for each OS. Generating such a system font list may be quite difficult for someone who doesn’t own that certain device, but it is very easy for those who own the device. As for me, I own a Xiaomi Redmi devices, this means I can generate a system font list for Android MIUI, specifically MIUI 12 based on Android 10. Here we go.
